# Tiger Training OS

An offline training log and progression app for a full-body-every-other-day (A/B/C) program, with
tendon pain monitoring, measurable calisthenics skill trees, athletic benchmarks and Obsidian
Markdown export. Plain HTML/CSS/JS, no dependencies, no build step, no server: your data stays in
your browser and your own exports.

Open the hosted page and add it to your home screen. Run locally with any static server, e.g.
`python -m http.server` in this folder.
